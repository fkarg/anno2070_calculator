Read: preserves every number as a column and lowers height, but is too dense to be the primary mode unless the user already knows the columns by heart.

Structural direction: make the app’s three sources explicit everywhere: Plan (hypothetical demand), Actuals (per-island buildings and productivity), and Coverage (capacity, bottleneck and partial satisfaction). Population’s default should be a read-only empire dashboard; manual planning belongs behind a named mode. Islands are the update surface, so show productivity inline and keep per-tier editing as a compact popover/drawer. Production is the audit surface, where fixed headers and immutable number tracks matter more than showing every input label.
